# Инструкции для ИИ-агента

Электронный словарь сербского языка: поиск по словоформам, ударения, связи с корнями,
пополнение через LLM.

## О проекте

- **Бэкенд**: Spring Boot, Java 25 (`/opt/java/jdk-25`), сборка Gradle
- **Фронтенд**: Vue
- **База**: Postgres
- **На будущее**: нативное приложение под разные ОС

Что словарь должен уметь: искать слово по любой его словоформе, показывать ударение
для слова и всех его словоформ, показывать разные значения слова раздельно, примеры
употребления, связь с русским / праславянским / сербским корнями.

## Исходные данные

`/home/ya-pashka/Documents/Srpski/Recnik/srb_rus_apk/srbbase.db` — sqlite-база из
Android-приложения «Serbian-Russian dictionary», 45 633 сербские статьи.

**Открывать только на чтение.** Утилита `sqlite3` в системе не установлена — работай
через `python3` с модулем `sqlite3` и URI-режимом `mode=ro`:

```python
sqlite3.connect('file:/home/ya-pashka/Documents/Srpski/Recnik/srb_rus_apk/srbbase.db?mode=ro', uri=True)
```

Чего в исходной базе нет и что предстоит вывести самим:
- чёткой части речи,
- разделения на значение и пример,
- разделения разных значений одного слова.

## Правила работы

- **Язык документации и комментариев — русский.**
- **План живой.** Перед задачей сверься с [docs/plan.md](docs/plan.md), после — отметь
  сделанное в том же изменении.
- 🚨 **Секретов в репозитории нет.** Пароль базы и ключи к моделям лежат в
  `secrets.properties` в корне — файл вне git; в git едет только
  `secrets.properties.template` с описанием ключей. Завёл новый секрет — тем же
  изменением добавь ключ в шаблон и строку в [README.md](README.md).
- **Не выдавай догадки за факты.** Формат исходной базы восстановлен обратной разработкой;
  где нет уверенности — пиши об этом прямо.
- **Правила кода** — [docs/CODE_REQUIREMENTS.md](docs/CODE_REQUIREMENTS.md).
