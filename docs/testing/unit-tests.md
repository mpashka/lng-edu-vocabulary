# Модульные тесты ядра

Родительский индекс: [index.md](index.md) · Код: `core/src/test/java/org/mpashka/vocabulary/core/`

JUnit 5, **87 проверок** в семи классах. Запуск:

```bash
./gradlew :core:test          # только ядро
./gradlew build               # всё, включая тесты
```

Отчёт — `core/build/reports/tests/test/index.html`.

## Что закреплено

| Класс | Проверок | Что закрепляет |
|---|---|---|
| `EntryParserTest` | 10 | разбор статьи: заглавное слово, значения, примеры, устойчивые обороты, омонимы |
| `SerbianTest` | 10 | кириллица → латиница и разбор знаков ударения |
| `PartOfSpeechRulesTest` | 16 | часть речи: по помете, по инфинитиву, по паре родовых форм, старшинство правил |
| `NounDeclensionTest` | 16 | склонение существительных: основные типы, беглое «а», чередования, варианты формы |
| `VerbConjugationTest` | 21 | спряжение глаголов: образцы, йотация, восстановление сокращённой записи формы |
| `AdjectiveDeclensionTest` | 3 | порождённые формы родов у прилагательных |
| `SourceFormsTest` | 11 | формы, выписанные в статье: где ударение своё, а где только буквы |

Разбиение внутри классов — вложенными `@Nested`-группами по темам, поэтому в отчёте
видно не только «сломалось спряжение», а какая именно его часть.

## Что тесты не проверяют

**Числа качества здесь не считаются.** Точность правила измеряется прогоном на всей
исходной базе — [rules-reports.md](rules-reports.md); модульный тест лишь закрепляет
разобранные случаи, чтобы правило не поехало молча при следующей правке.

Тестов бэкенда нет. На фронтенде `npm test` проверяет преобразование алфавита,
расшифровку помет словоформ вместе с разбором формы по правилу и сборку обращения об
ошибке (что уезжает в issue, как урезается длинный адрес) — то, что можно проверить
без браузера.
