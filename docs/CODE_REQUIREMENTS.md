# Требования к коду

Родительский индекс: [index.md](index.md). Общие критерии качества кода приходят агенту
сами на первой правке кода; здесь — только то, что своё у словаря.

- **Правила проверяются на выборке.** Любой набор правил (часть речи, словоформы)
  сопровождается прогоном на выборке из исходной базы и оценкой точности —
  [testing/](testing/index.md).
- **Никакой привязки к одному поставщику моделей.** Начинаем с Yandex, но обращения к
  модели идут через собственный интерфейс, а поставщик выбирается настройкой —
  [implementation/llm.md](implementation/llm.md).

## Тэги в коде

Токен `@tag:<slug>` — в комментарии прямо над элементом; где у элемента уже есть Javadoc
или JSDoc, тэг ставится в него. Несколько тэгов — через пробел. Тэг сначала заводится в
[tags.md](tags.md).

- **Java** — канон llm-wiki-tags, `rules/code-tags-java.md`: пакет — в Javadoc
  `package-info.java`, файл — над строкой `package`, класс и метод — над объявлением.
- **JavaScript и Vue** (в каноне их нет): директория — тэг в её `index.md`; файл —
  комментарий в самом верху, до первого `import`; компонент `.vue` — первой строкой блока
  `<script setup>`, а не в `<template>`; функция и класс — над объявлением.
