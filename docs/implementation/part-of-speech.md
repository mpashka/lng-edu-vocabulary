# Правила определения части речи

Родительский индекс: [index.md](index.md) · Код: `core/…/PartOfSpeechRules.java` ·
Отчёт о качестве: `importer/…/PartOfSpeechReport.java`

В исходной базе части речи нет. Она выводится двумя путями: по **грамматической помете**
и, если пометы нет, по **строению статьи**. Помета сильнее строения.

## Как измеряется качество

Ручной разметки не потребовалось: образец для сверки даёт сама база. У статей, где часть
речи названа явной пометой, помету **скрывают** и смотрят, восстановят ли её структурные
правила. Так измеряется точность строения на 29 127 статьях без единого размеченного вручную
слова.

Запуск: `./gradlew :importer:run`

## Достигнутое качество

| Мерка | Значение |
|---|---|
| Часть речи определена | **45 483 из 45 633 (99,7 %)** |
| Не определена — уйдут к языковой модели | 150 (0,3 %) |
| Точность строения при скрытой помете | **97,9 %** |
| Статей без пометы, разобранных строением | 16 339 из 16 489 (**99,1 %**) |
| Глаголы: восстановлено из скрытых помет | **6 167 из 6 167, ошибок 0** |

Распределение: существительные 21 398 (46,9 %), глаголы 14 899 (32,6 %),
прилагательные 7 648 (16,8 %), наречия 1 238 (2,7 %), остальные части речи — сотни.

> Оговорка о числе 97,9 %. Это **осторожная оценка**: она снята с пометами, скрытыми
> нарочно. В работе помета имеет приоритет, поэтому строение решает только судьбу
> 16 489 статей без пометы. Большая часть оставшихся ошибок приходится на местоимения
> и числительные, которые склоняются как прилагательные и структурно от них неотличимы, —
> но у них-то помета как раз есть, так что до показа эти ошибки не доходят.

## Правило 1. Явная помета

Помета — фрагмент с пустой пометой разметки, за которым идёт точка: `ж$#.#`, `несов$#.#`.

| Помета | Часть речи |
|---|---|
| `м`, `ж`, `с`, `собир` | существительное |
| `сов`, `несов`, `многокр`, `безл` | глагол |
| `прил` | прилагательное |
| `нареч` | наречие |
| `мест`, `вопросит`, `относит` | местоимение |
| `числит`, `порядк` | числительное |
| `межд` | междометие |
| `союз` | союз |
| `предл`, `предлог` | предлог |
| `частица` | частица |

Прочие пометы (`уст`, `обл`, `бот`, `тех`, `перен`…) часть речи не называют, но нужны,
чтобы отличать помету от обычного текста.

### Три ловушки

**`ср` — это «сравни», а не «средний род».** Средний род обозначен через `с`. Помета `ср`
в таблицу не входит намеренно.

**`с` из составного сокращения `с.-х.`** (сельскохозяйственный) читалась как средний род:
глагол `це’пити` («мед., с.-х. прививать») объявлялся существительным. Признак составного
сокращения — дефис сразу после точки. Затрагивало 17 статей, причём они портили и сам
образец для сверки.

**«предлог с род. п.»** — статья предлога пишет часть речи полностью, а таблица знала только
сокращение `предл`. Следующее `с` («с родительным») читалось как средний род, и `из`, `од`,
`кроз`, `око` были существительными (найдено 2026-10-04, lev-79). После правки предлогов
83 статьи вместо ни одной: 60 были существительными, 5 — наречиями, 18 — без части речи.

## Правило 2. Глагол — по инфинитиву

Сербский инфинитив оканчивается на **`-ти`** либо **`-ћи`**, возвратный — с частицей `се`.

Проверено на всей базе: из 6 165 статей с пометой `сов`/`несов`/`многокр` на `-ти`/`-ћи`
оканчиваются **все до единой**. В обратную сторону — 44 ошибки на 14 971 слово (0,3 %):
существительные во множественном числе вроде `Благовести`, `Карпати`, `ефекти`, `девчићи`.
У всех у них есть явная помета, которая правило перекрывает.

### Отвергнутое правило

Сначала глагол определялся по **второй форме на `-м`** (первое лицо настоящего времени:
`ра’дити, ра^ди_м`). Правило оказалось хуже: за глаголы принимались

- `Амстердам (а’мстердам)` — вариант написания в скобках оканчивается на `-м`;
- `ба“рем, ба^рем` — наречие с двумя вариантами ударения.

Замена на правило инфинитива подняла покрытие с 94,8 % до 99,0 % и убрала эти ошибки.

## Правило 3. Прилагательное — по формам родов

Прилагательное узнаётся по **паре родовых форм**: женский род на `-а` и средний на
`-о` либо `-е`. Формы пишут и через тильду (`~на`, `~но`), и целиком (`бе’ла`, `бе’ло`).

```
а‛псурд||ан, ~ни_, ~на, ~но     → прилагательное
би’вољ||и_, ~а_, ~е_            → прилагательное (мягкое: средний род на -е)
да’дин, ~а, ~о                  → прилагательное (притяжательное)
```

### Что пришлось уточнить

**Одной тильды мало.** Через тильду записывают и падежные формы существительных, поэтому
`бе‛збедн||о_ст, ~ости` и `де‛те_нц||е, ~ета` объявлялись прилагательными. Требование пары
родовых окончаний это убрало.

**Средний род не всегда на `-о`.** Мягкие прилагательные (`ба“бљи, ~а_, ~е_`) имеют его на
`-е`; без учёта этого 2 279 прилагательных оставались неопознанными.

**Мужской род на `-и` требовать нельзя.** У притяжательных его нет (`да’дин, ~а, ~о`);
требование обрушило покрытие с 99,7 % до 94,0 %.

## Правило 4. По смыслу — где нет ни пометы, ни строения

Код: `PartOfSpeechRules.detectByMeaning`, срабатывает при разборе статьи последним.

- Восклицательный знак у заглавного слова — **междометие** (`а̀ма̄н!`, `џа̏нум!`).
- Безударное служебное слово ([word-forms.md](word-forms.md), «Безударные слова») — по
  классу своего перевода: русский предлог — **предлог**, союз — **союз**, частица,
  личное местоимение. `да` и `хоть` двусмысленны и части речи не дают.

Проверено вслепую на статьях с пометой (`:importer:run`): 105 верно, 3 ошибки — **97,2 %**.
Ошибки — наречия-команды с `!` (`одаље!`, `вољно!`) и `през`.

## Правило 5. Викисловарь — где правила не справились

Код: `importer/…/WiktionaryPartsOfSpeech.java`, `./gradlew :importer:wiktionaryPartsOfSpeech`
(после переноса и до записи ударений; повторяемый — сначала возвращает записанное прошлым).

Словам с `UNKNOWN` часть речи берётся из статьи викисловаря с теми же буквами, если
**заглавное ударение совпало по тону** ровно с одной частью речи — без этой опоры омограф
дал бы чужую часть речи. Записывается `part_of_speech_source = WIKTIONARY`, причина
«часть речи не определена» снимается.

Точность меряется тем же прогоном на словах, чья часть речи известна по помете, — отдельно по
каждой части речи, которую назвал викисловарь, — и берётся только надёжная: от 95 % на 30 и
более словах. Порог проверяет код на свежих числах. Прогон 2026-10-04:

| Часть речи викисловаря | совпало / разошлось | |
|---|---|---|
| существительное | 6 628 / 46 — 99,3 % | берётся |
| глагол | 3 499 / 3 — 99,9 % | берётся |
| прилагательное | 1 714 / 51 — 97,1 % | берётся |
| наречие | 320 / 22 — 93,6 % | нет |
| местоимение, числительное, союз, частица | 85,7 % и ниже | нет |
| предлог | 0 / 19 | нет |

Предлог показателен: все 19 слов, которые викисловарь назвал предлогом, у словаря с пометой
другой части речи — служебное слово в словаре и в викисловаре расписано по-разному.

Итог (до правки «предлог с род. п.» и правила 4): из 180 слов без части речи определено **41** (короткие прилагательные `бла̑г`, `до̏бар`,
`жи̑в`, существительные `пчѐла`, `по̀љубац`, глаголы `вѐлӣм`); 11 — часть речи викисловаря
ненадёжна; 128 — опоры нет (заглавное без тона) или неоднозначно.

## Что остаётся языковой модели

132 статьи, где ни помета, ни строение, ни смысл не сработали (было 150 до правила 4 и
ловушки «предлог с род. п.»). Это в основном:

- слова, у которых часть речи задана словами, а не пометой: `архи...` («приставка,
  означающая…»), `а‛ма_н!` («восклицание»);
- статьи вида «заглавное слово : устойчивое сочетание» без собственного перевода:
  `а‛рми_рани_ : ~ бетон — железобето’н`, `ба“биња : ~ грозница`.

Они получают `UNKNOWN` и попадают в очередь на разбор языковой моделью (этап 9), если
часть речи не дал викисловарь (правило 5). После всех правил таких слов 107 (2026-10-04).

## Известные пределы

- **Местоимения и числительные структурно неотличимы от прилагательных** — склоняются
  одинаково. Спасает только явная помета.
- **Существительные во множественном числе на `-ти`/`-ћи`** попадают под правило
  инфинитива. Тоже спасает помета.
- **Часть речи одна на статью.** У омонимов, упакованных в одну строку, части речи могут
  различаться (`gora` — существительное в обоих значениях, но бывает и вперемешку).
  Разделение омонимов отложено до этапа 4, см. [source-db.md](source-db.md),
  раздел 7.3.
